# Aditya Epoch / CampusX

## Live Demo
- Frontend: https://campus-x-lemon.vercel.app
- Backend API: https://campusx-backend-production-c272.up.railway.app

## Summary
Aditya Epoch is a modern college admissions website for Aditya Degree College, built with React, Tailwind CSS, and Vite on the frontend, and Node.js + Express + SQLite on the backend.

Features include:
- Responsive campus website
- Online admissions form
- Contact form
- Testimonials video gallery
- Admin login and submission review
- Live deployment on Vercel and Railway

## Notes
- The frontend is connected to the backend using the `VITE_BACKEND_URL` environment variable.
- Use the `Admin Login` button in the navbar to access admin submission review.
